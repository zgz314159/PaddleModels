| 2026-10-02 | Fix: fingerprint v2 page cache inputs | `pipeline/page_cache.py` (new), `pipeline/v2_runner.py`, `models/run_context.py`, `tests/test_page_cache.py` (new), `docs/SCRIPT_FUNCTION_MAP.md` | The active v2 page cache is now keyed per page on an explicit schema version plus a SHA-256 fingerprint over the IR-affecting profile config, the PageRouter threshold and the per-page route strategy. A hit requires a matching metadata envelope (schema version, fingerprint, input SHA, page number, strategy); legacy bare `page_N.json`, missing fields, wrong page/strategy, and corrupt/truncated JSON are safe misses that warn but never delete, overwrite or fail the run. Writes use a same-directory temp file plus `os.replace`. Existing `.cache` files are isolated by a new `pages_v2` namespace and are never cleaned. |
